## Design Context

### Users
Claude Code and Claude Desktop users who want to earn a share of ad revenue while doing their existing work. The landing page collects waitlist signups for an unreleased mod.

### Brand Personality
Minimal, direct, independent. Use a calm and candid voice. Do not promise unconfirmed earnings, payouts, or launch dates.

### Aesthetic Direction
Use the original mux layout: a narrow, left aligned column, a black background, modest type sizes, and generous line spacing. The user prefers its simple reading flow. Keep the page mostly monochrome, with warm color reserved for the Claude preview. Match the sponsored strips in the user's Claude Code and Desktop references. Use the same dark palette and direct voice in the welcome email.

The welcome email uses the simple text structure of Modal's emails: one column, a small heading, short paragraphs, an inline social link, and a personal sign-off. Avoid decorative labels, large headings, repeated links, and extra buttons.

### Design Principles
1. Keep one signup form near the top. Avoid repeated sales sections or calls to action.
2. Show both Claude products through an interactive preview.
3. Show short answers directly in the page instead of hiding them in accordions. Explain the unreleased product in the early access copy. Do not add a disclaimer label below the preview.
4. Make controls accessible and respect reduced motion.
5. Use @guard_if for product updates.
6. Use Phosphor bold SVG icons for interface symbols. Keep sizes and optical weight consistent. Use original Claude and sponsor logos from their official websites. Preserve their shapes and choose a version with clear contrast.
7. Keep Claude Desktop recognizable, but simplify the task-view screenshot for the small preview. Use a white window, a short task title, one brief chat exchange, a gray sponsored strip above the command input, and only the essential model controls below. Remove extra header icons, the project chip, and activity details. Keep the ad copy short and its CTA below the copy.
8. Show the Baseten mark as a black B on a green square (#19E76E). Set “Baseten” beside it as regular interface text, not the brand wordmark.
9. Match Claude Code to the user's terminal screenshot. Use its orange block mascot, startup version/model/directory lines, highlighted user prompt, plain command input between horizontal rules, block cursor, and yellow auto mode status. Keep the ad CTA below the ad copy.
10. Animate both previews with a brief thinking state, a streamed response, then a soft ad entrance. Reserve the final layout throughout. Play once when visible, replay on platform selection or the replay button, and pause outside the viewport or in a hidden tab. Show the complete static preview for reduced motion.
