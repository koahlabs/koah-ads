# mux landing

Minimal landing page for [`@koah/mux`](https://github.com/koahlabs/clis/tree/main/js/mux) — a split terminal with a Koah ad strip.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

```bash
npx vercel
```

Or import the repo at [vercel.com/new](https://vercel.com/new). Next.js is detected automatically.
